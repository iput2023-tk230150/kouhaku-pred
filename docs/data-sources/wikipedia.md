# Wikipedia

## 概要

WikipediaのMediaWiki APIを使用して、紅白歌合戦の出場者情報を取得します。

- **対象Step**: Step 3（紅白出場者取得）
- **取得内容**: 各回の紅白歌合戦出場アーティスト一覧

## データソース

| 項目 | 内容 |
|------|------|
| API | Wikipedia MediaWiki API |
| URL | https://ja.wikipedia.org/w/api.php |
| アクション | parse（ページHTML取得） |
| ライセンス | CC BY-SA 3.0 |

### 取得対象ページ

各年の紅白歌合戦ページを取得します。

例:
- 第75回NHK紅白歌合戦（2024年）
- 第76回NHK紅白歌合戦（2025年）

## 処理内容

1. 指定年度の紅白歌合戦ページをAPI経由で取得
2. HTMLをパースして出場者テーブルを抽出
3. 開催前/開催後の2形式に対応してパース
4. アーティスト名の重複排除、企画枠除外

### 開催前/開催後のテーブル形式

**開催後形式**: 曲順・歌手名・組カラムを含むテーブル
```
| 曲順 | 歌手 | 曲名 | 組 |
```

**開催前形式**: 紅組・白組が横並びのテーブル
```
| 紅組 | 白組 |
```

## 使用ライブラリ

- `requests`: HTTPリクエスト
- `beautifulsoup4`: HTMLパース

## 出力ファイル

**ファイル**: `data/raw/kouhaku/kouhaku_artists.csv`

| カラム | 説明 |
|--------|------|
| year | 審査年（紅白開催前年） |
| artist | アーティスト名 |
| group | 紅組 / 白組 |

## 設定項目

`config.toml`で以下の設定が可能です。

```toml
[kouhaku.target_years]
2015 = 66  # 2015年は第66回
2016 = 67
2017 = 68
2018 = 69
2019 = 70
2020 = 71
2021 = 72
2022 = 73
2023 = 74
2024 = 75
2025 = 76

[network]
request_timeout = 30  # タイムアウト（秒）
request_interval = 1  # リクエスト間隔（秒）
```

## 注意点・制限事項

### APIレート制限

- リクエスト間隔を1秒以上に設定
- WikipediaのAPIポリシーに従う

### キャッシング

- 既存データを保持し、今年度データのみ再取得する機能あり
- 過去データは変更されないため、毎回全取得は不要

### パース精度

- 注釈リンク（`[注釈]`形式）は除外
- 数字のみ（出場回数など）は除外
- グループ判定（紅/白）は特定のテーブル形式でのみ確実

### その他

- エンコーディング: UTF-8 BOM付き（utf-8-sig）
- 複数年出場アーティストの検出機能あり（3回以上）
